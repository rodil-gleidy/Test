# Python antes del MBA (USP/Esalq)

Cinco casos prácticos para practicar Python con datos. Cada notebook tiene:

1. **El caso**: la historia, las preguntas de negocio y el diccionario de datos.
2. **Paso 0**: código que genera la base de datos (ejecútalo primero).
3. **Parte A**: el paso a paso en comentarios, para que escribas el código.
4. **Parte B**: la solución comentada.

| Notebook | Tema |
|---|---|
| `00_configuracion_y_calentamiento.ipynb` | Configuración (Colab / Anaconda) y Python básico |
| `00b_practica_for.ipynb` | Práctica extra: 15 ejercicios del bucle `for` |
| `00c_practica_comprensiones.ipynb` | Práctica extra: 15 ejercicios de comprensiones de lista y diccionario |
| `00d_repaso_errores.ipynb` | Repaso: 15 ejercicios sobre los 4 errores más frecuentes (detective y desde cero) |
| `00e_rehacer_repaso.ipynb` | Rehacer: los ejercicios 8, 12, 13 y 14 del repaso, sin pistas |
| `01_loja_verde_ventas.ipynb` | E-commerce: limpieza, merge, groupby, RFM y dashboard |
| `02_cafe_estadistica.ipynb` | Cooperativa de café: estadística descriptiva, pruebas de hipótesis y regresión |
| `03_delivery_series_tiempo.ipynb` | Delivery en São Paulo: fechas, series de tiempo y dashboard operativo |
| `04_redes_sna.ipynb` | Análisis de redes (networkx): centralidades y comunidades |

Para abrirlos en Google Colab: **Archivo → Abrir notebook → GitHub** y busca este repositorio.
